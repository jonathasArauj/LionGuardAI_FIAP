# Amostras enviadas pelo usuário

Quatro imagens de peixe-leão enviadas na conversa, utilizadas como exemplos positivos no treinamento **experimental**. Incluídas neste pacote para uso acadêmico privado/reprodução local; **não foi fornecida licença/autoria original**. Antes de publicar ou redistribuir as imagens, identificar titulares e obter autorização. O manifesto inclui os SHA-256.

**ATENÇÃO:** exemplos do treino não podem ser reaproveitados para medir acurácia, precisão, recall ou F1 como se fossem observações de teste independentes. Um classificador com esta base não está validado para identificar a espécie em campo.
