# assets

Elementos não estruturados do projeto: imagens, logotipos e demais recursos
visuais.

| Conteúdo | Onde está |
| --- | --- |
| Identidade visual (paleta, CSS, cores de status) | `app/styles/theme.py` |
| Figuras geradas para o PDF da entrega | `reports/figuras/` (geradas por `scripts/gerar_pdf.py`) |
| Diagramas da arquitetura | `docs/arquitetura.md` (Mermaid, renderizado pelo GitHub) |

As figuras e os diagramas são **gerados a partir do código e dos dados**, e não
desenhados à mão — por isso ficam junto de quem os produz, e não copiados para
cá. Esta pasta existe para recursos estáticos que venham a ser adicionados.
